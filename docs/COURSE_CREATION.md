# Course Creation & Management

## How Courses Work

The platform enables mentors to create and manage courses, which students can discover and enroll in.

### Course Lifecycle

1. **Mentor Creates Course** → Use the "Create Course" button on `/dashboard/mentor/courses`
   - Fill in: Title, Description, Category, Level (beginner/intermediate/advanced), Price
   - Course is automatically published and visible to students

2. **Students Discover Courses** → View all published courses on `/dashboard/courses`
   - See course details: title, description, mentor info, pricing
   - Can preview course before enrolling

3. **Student Enrolls** → Click "Enroll in Course" on course detail page
   - Creates enrollment record in Firestore
   - Student gains access to course tasks

4. **Course Management** → Mentor dashboard shows:
   - Number of enrolled students
   - Course rating
   - Revenue tracking
   - Edit/Delete buttons (UI present, backend coming soon)

## Course Creation UI

### Quick Access
- **Location**: `/dashboard/mentor/courses`
- **Button**: "Create Course" (top right)
- **Dialog**: Modal form with fields below

### Form Fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| Course Title | Text | Yes | e.g., "React Advanced Patterns" |
| Description | Textarea | Yes | What students will learn |
| Category | Dropdown | Yes | React, Backend, Frontend, DevOps, Database, Other |
| Level | Dropdown | No | beginner, intermediate, advanced (default: beginner) |
| Price | Number | No | USD amount (default: 49.99) |

### Submission
- Click "Create Course"
- Course appears immediately in mentor's course list
- Published automatically and visible to students

## Student Course Enrollment

### Flow
1. Student browses `/dashboard/courses`
2. Clicks course title to view details at `/dashboard/courses/[courseId]`
3. Reviews course content and mentor info
4. Clicks "Enroll in Course" button
5. System creates enrollment record and shows "✓ Enrolled"

### Enrollment Validation
- Student can submit tasks only for enrolled courses
- Enrollment check is performed before task submission
- Prevents unauthorized task submissions

## Troubleshooting

### No courses appearing in student list
- Check that courses are published (`isPublished: true`)
- Verify mentor UID is correct in `ownerId`
- Check Firestore rules allow reading courses collection

### Enrollment failing
- Ensure Firestore `enrollments` collection exists (auto-created on first write)
- Check student is logged in (`user.uid` is defined)
- Verify course ID is valid

### Course creation failing
- Ensure user is logged in as mentor
- Check required fields are filled (title, description, category)
- Verify Firestore `courses` collection is writable
